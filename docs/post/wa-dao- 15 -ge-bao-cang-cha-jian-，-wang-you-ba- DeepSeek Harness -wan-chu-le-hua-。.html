**02

一次装好常用界面功能**

dsh-web-ui-all 把常用的 DSH Web 插件做成了一个全家桶。

支持任务看板、Git 记录、实时统计、远程访问、桌面宠物和皮肤。

这一套界面套餐，适合先整体体验，再决定长期保留哪些功能。

如果只喜欢其中一两个，也可以单独安装对应的小插件，让界面保持清爽。

**03

DSH Better Sidebar**

DSH Better Sidebar 给网页增加了右侧栏和底部面板。

你可以在里面浏览文件、编辑代码、预览文档、运行终端、查看改动，还能看到子 Agent 正在做什么。

这个确实还挺方便的，类似 Codex 的客户端也有相应的能力。

装上以后会方便不少。

**04

给终端党准备的 DSH**

有些人喜欢网页，有些人喜欢终端。

dsh-TUI 做了一套类似 Claude Code 的终端界面，可以显示 Agent 工作状态、上下文用量和模型用量。

当然，也支持搜索历史、切换模型、引用文件、恢复会话和查看子 Agent。

输入 @ 可以查找项目文件，历史消息也能随时搜索。

任务做得太久时，可以压缩会话或导出记录。如果 Agent 方向不对，还能回到前面的节点重新开始。

开源地址：https://github.com/ccch1mneyyy/dsh-TUI

**05

给 Agent 一套完整的视觉工具**

DSH Vision Toolkit 把图片理解等能力搞成了一个工具箱。

它能做图片问答、长截图文字识别、元素定位、图片裁剪和像素对比，生成的结果也可以保存下来继续使用。

一个常见场景是把设计图交给 Agent，让它先找到页面里的按钮、卡片和颜色，再写出网页。

完成后重新截图，与原图比较差异，然后继续修改。

整个过程有图片和数据可以检查。

开源地址：https://github.com/Anionex/dsh-vision-toolkit

**06

让 DSH 操作你正在使用的浏览器**

dsh-browser 连接你正在使用的 Chrome 标签页。

它能读取页面、点击按钮、填写表单、滚动和跳转，同时保留现有的登录状态和 Cookie 啥的。

侧边栏里还有一套 DSH 对话界面，可以边聊边操作网页。

它不会把整张网页截图交给模型，而是把页面整理成带编号的文字和控件列表。

密码、银行卡号这些敏感输入会被遮住，点击、填写和跳转等操作也需要人授权。

它由 DSH 插件和 Chrome 扩展两部分组成，安装步骤比普通插件多一点。

开源地址：https://github.com/Lum1104/dsh-browser

**07

换套皮肤**

这一块是社区里最热闹的一类项目，就是给界面换皮肤。

它们大多不会改变模型能力，主要负责外观、布局和聊天气氛。

鲸鱼娘与深海女仆风

dsh-deep-whale 里的 maid-atelier 皮肤采用深海蓝界面，提供亮色、暗色背景和双女仆角色。

角色位置会根据页面宽度调整，尽量不挡住聊天区域。

项目目前有 1500 Star，皮肤采用非商业许可证，商业使用需要留意。

开源地址：https://github.com/Small-tailqwq/dsh-deep-whale/tree/main

2006 年的 QQ

QQ 2006，蓝色标题栏、好友列表、聊天工具栏和 QQ 秀。

开发者还准备了经典蓝、粉红、薄荷绿和紫罗兰等配色。

开源地址：https://github.com/LaplaceYoung/dsh-qq2006

把 Token 用量做成股票行情

这个把 DSH 做成了同花顺风格的红色行情终端。

项目列表像自选股，Token 消耗会显示成 K 线。。。

代码增加和删除则变成成交量柱。

开源地址：https://github.com/renat3u/tonghuashun-webui

在 Excel 里和 Agent 聊天

dsh-deepcel 把 DSH 的导航、会话、工具和设置重新排成工作表单元格。

亮色模式像办公室里的 Excel，暗色模式则更像一张夜间数据表。

开源地址：https://github.com/Small-tailqwq/dsh-deepcel

让 AI 回复带上自己的表情包

**08

让多个 Agent 组队干活**

dsh-agent-teams 可以在当前会话里建立一支 Agent 小队。

一个 Agent 负责带队，把目标拆成多个任务，再分别交给不同成员。

成员之间可以传递消息，也能等待前置任务完成后再接着工作。

开源地址：https://github.com/NanmiCoder/dsh-agent-teams

**09

这 3 个项目早于 DSH，后来才加入适配**

下面三个项目的主体都早于 DSH。

它们原本服务于更广泛的 AI Agent 和开发工具，DSH 发布后，项目又增加了对应的插件或适配方式。

OpenViking：让 Agent 记住你的项目

OpenViking 能给  DSH 配一套长期笔记。它会保存过去的对话和重要信息，下次遇到类似问题时，再把相关内容找出来。

你也可以让 Agent 搜索、补充或删除记忆。

开源地址：https://github.com/volcengine/OpenViking/tree/main/examples/dsh-memory-plugin

从聊天和 Git 记录里学习

很多项目约定没有写进文档，可能只存在于一次聊天或某条 Git 提交记录里。

时间久了，人和 Agent 都容易忘。

Hindsight 会在后台整理这些信息，慢慢建立一份项目知识库。

以后无论使用 DSH、Codex 还是 Claude Code，Agent 都能找回与当前任务有关的经验。

它还会整理项目架构、团队习惯和正在推进的工作。

项目目前约有 2 万 Star。想让多个编码工具共用同一份项目记忆，可以重点看看它。

把截图交给纯文本模型

ModLens 也是让 DSH 能看懂图片的插件。

装好后，粘贴图片就能提问。它会先读出图片中的文字、布局和关键内容，再交给 DeepSeek 分析。

你可以把报错截图丢给它，问问题出在哪里。

也可以上传网页截图，让它说明页面结构。

遇到复杂图表或一批风格相近的图片，它也能按顺序整理重点。
