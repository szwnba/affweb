AI 帮你自动收集新闻！

Agently Daily News Collector 是一个基于 Agently AI 应用开发框架的开源大型语言模型（LLM）新闻自动收集工作流项目。

用户只需简单地输入感兴趣领域的新闻，AI 代理将自动完成收集工作，总结成高质量的新闻并保存到 Markdown 文件中。

该开源项目有一个简单易用的界面，可以自定义新闻收集的参数，并通过 AI 技术自动搜索、筛选、总结生成新闻报道。项目支持多种输出格式，包括 Markdown 和 PDF 文件。

项目的使用步骤如下：

1. 克隆仓库：

git clone git@github.com:AgentEra/Agently-Daily-News-Collector.git

2. 编辑设置 YAML 文件，输入模型的 API 密钥并根据需要更改其他设置。

3. 安装 Python 并运行项目：

pip install -r requirements.txt
python app.py

4. 输入新闻收集的领域主题，AI 将自动开始收集新闻。

输入你想要汇总的新闻领域主题关键词，或是用一句话描述您想要生成什么样的新闻汇总报告，然后任务就会开始自动运行了。

5. 收集完成后，将在项目目录中生成一个 Markdown 文件，包含收集的新闻。
