01

视频翻译神器

开源神器 PyvideoTrans 能将你喜爱的视频从一种语言翻译成另一种语言，并且添加配音。这个神器不仅为视频内容的国际化提供了便利，也为视频创作者和翻译者开辟了新的合作路径。

演示配图

PyvideoTrans 通过集成先进的翻译 API 和语音合成技术，实现了视频内容的自动化翻译和配音。这不仅大大节省了人力成本，也提高了翻译的效率和质量。

开源地址：https://github.com/jianchang512/pyvideotrans

核心功能

视频翻译： 将视频中的声音翻译为另一种语言的配音，并嵌入该语言字幕

字幕管理： 从音频、视频中提取字幕文件，根据字幕文件创建配音，将一个或多个字幕文件翻译为其他语言的字幕文件

音视频操作： 从视频中分离为音频文件和无声视频、可从油管上下载视频

02

探索 MetaGPT：一群 AI 帮你写代码

MetaGPT 是由 geekan 发起的开源项目，它是一个多智能体框架，它的目标是让 AI 以互联网公司组织的方式自由协作，帮助你开放复杂的软件或系统。

开源地址：https://github.com/geekan/MetaGPT

目前该项目已经获得了惊人的 43k 的 Star！

说白了就是对着 MetaGPT 输入一句话的老板需求，它自动帮你输出用户故事 / 竞品分析 / 需求 / 数据结构 / APIs / 文件等

从代码审查到问题跟踪，从安全漏洞的发现到修复，MetaGPT提供了一整套解决方案。

03

自动帮你处理 GitHub issue

SWE-agent 会处理 GitHub issue 并使用 GPT-4 或你选择的d自动修复它，仅需 1 分钟即可运行。在 SWE-bench上 ，SWE-agent 解决了 12.47% 的问题，在全测试集上表现挺不错的。

开源地址：https://github.com/princeton-nlp/SWE-agent
