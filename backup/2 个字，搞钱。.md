在这个数字化飞速发展的时代，小程序以其便捷性、易用性成为连接用户与服务的桥梁。

很多人也把小程序作为变现的渠道，比如之前很火的羊了个羊、妙鸭相机等都看中了小程序渠道。

而今天，我们要探索的是一个能够将 Comfyui 工作流一键转换为微信、抖音小程序等平台的神奇工具：ComfyUI-Bxb

**简单说就是将你搭建的文生图工作流，发布成一个带支付功能小程序，使用小程序的用户可以通过付费的方式来AI 生图**

**🔥 项目简介**

SD变现宝，一个由开发者 zhulu111 精心打造的开源项目，致力于简化开发者的工作流程，让变现变得更加轻松。

它不仅**支持微信小程序、抖音小程序的一键转换，还涵盖了微信内 H5 和微信外 H5，且都支持支付功能，为开发者提供了一个全方位的变现解决方案**。

**🔥 Comfyui是啥？**

介绍这个项目之前，先讲讲 ComfyUI 是啥？

简单说 ComfyUI 就是一个工作流，是专门为 Stable Diffusion（很火的文生图开源模型） 定制的神器，它基于节点化设计，将图像生成过程划分为多个独立但功能明确的模块。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/ePw3ZeGRruwZvgIeZOaCy5jPIaPzq5ibzOXxficBEVsqVbuolicIax767x6vNrHxPC1IrOOeBbLVQP7TFoHdqY22g/640?wx_fmt=png&from=appmsg)

这些模块，也就是节点，各自承担着特定的任务，如模型加载、文本输入、图像生成等。**用户可以通过将这些节点通过输入输出线连接起来，构建出完整的图像生成流程。** 

这种设计使得用户能够灵活地调整和优化图像生成的各个环节，实现个性化的创作过程。

**👍 核心功能**

回到主题，今天推荐的开源项目 **ComfyUI-Bxb 支持将 ComfyUI 工作流快速转换为多个平台的小程序。所有转换后的小程序均支持支付功能，为变现提供可能。** 完美支持Windows、Linux、Mac三大主流操作系统。

**💻 部署流程**

ComfyUI-Bxb 的安装方式非常简便，可以参考该开源项目的主页或者作者在 B 站上的介绍：  

1\. 通过 ComfyUI-Manager 在线安装，搜索“ComfyUI\_Bxb”即可。

2\. 使用 git clone 下载插件包，放置到指定目录下，重启 ComfyUI 完成安装。
