神仙级别开源项目推荐：GitHub-Chinese-Top-Charts。虽然没有一行代码，但在 Github 上却拥有令人咋舌的 71.6K Star。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/o3oSjHMHKLFCchWs2VY2uM9DicCIZwU61micQibrtn4Zk1QJK6gBtD8ZsV9wvA5bJbbj8aIfroTWFnl4WrqMLOckA/640?wx_fmt=png&from=appmsg)

与其说它是一个项目，不如说它是一个榜单。它将 Github 上所有的中文项目按照 Star 数进行整理和排行，如中文总榜、中文增速榜、中文新秀榜。并根据不同的开发语言分成了不同的子榜单。如软件类，资料类：

![](https://mmbiz.qpic.cn/sz_mmbiz_png/o3oSjHMHKLFCchWs2VY2uM9DicCIZwU61zbjB7QSvTLLlVb3PfZIYoYJZGx0ARxjjTI2Ar26BSZUtrnPs9k2nQg/640?wx_fmt=png&from=appmsg)

![](https://mmbiz.qpic.cn/sz_mmbiz_png/o3oSjHMHKLFCchWs2VY2uM9DicCIZwU61LMJmd9XN2XyacVAsnNib7BUyhMdUgokYUw7ic68QuVdOv2Jzaa0elkEQ/640?wx_fmt=png&from=appmsg)

此外他还提供了一个英文榜单，整理了所有编程语言学习资料的排行榜。开源地址：

https://github.com/GrowingGit/GitHub-English-Top-Charts

截至目前，已经整理了三十多种开发语言的项目。

以 Java 语言为例，在 Java 语言软件榜单中，它按照Star数对所有中文的 Java 开源项目进行了排序。这里看到 Java 软件类排行榜，其中包括了阿里的企业级开源项目：dubbo排名第二，arthas 排名第五。如图所示：
