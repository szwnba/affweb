一、怎么接：三步，一分钟
------------

路径不长，核心是 WorkBuddy 里有个**「公众号运营专家」**。它是专门干这活的，你不用自己写一行接口代码。

![](https://mmbiz.qpic.cn/mmbiz_png/3iaC372xTyEkVXKY3TgxSNiaev7rChe2JFa0pONfbMTrSBHZdCics5vdTH1QxiakcNP6vr9p8lvI863ohekQpcdAXFa5OiazJB219lia8689Xtmdg/640?wx_fmt=png&watermark=1#imgIndex=1)

**第一步：进专家，搜“公众号”。** 打开 WorkBuddy，点左侧「专家」，搜索框里敲“公众号”，出来的结果里选「公众号运营专家」。

**第二步：等它加载完。** 第一次进会跑一会儿，加载完它会先自我介绍一遍能干嘛——别急，让它说完。

**第三步：对它说一句话。** 直接输：“我需要写公众号，你帮我接入微信公众号后台。” 它会要你填两个东西——**AppID 和 AppSecret**，这俩在公众号后台「开发 → 基本配置」里拿。填完，通了。

就这三步。你不是在“开发”，是在“吩咐”。

三、我踩过的三个真坑（你照着避）
----------------

教程里演示到一半重启了，说明这活儿看着简单也有暗坎。我替你踩了一遍：

**坑 1：AppSecret 重置。** 旧 secret 一调就报 40125（invalid appsecret）。原因多半是你在公众号后台重置过密钥，旧值就废了。去「基本配置」重置拿新值填上就行。

**坑 2：IP 白名单。** 调接口的服务器 IP 得加进「IP 白名单」，否则报 40164。把报错里那个 IP 加进去就通。

**坑 3：本机代理离线。** 我电脑上的出网代理当时挂了，别慌——直接直连微信 API 反而返回 200。代理死了就用直连，别在代理上死磕。

按上面三步来，基本一遍过。坑都是我替你趟平的。
