一、选题的重要性
--------

选题的重要性不言而喻。

主题是内容创作的起点，决定了内容的方向和深度。

好的选题能够紧扣读者的需求，提供读者真正关心和价值的信息，从而增强内容的吸引力和粉丝的粘性。

而在内容的传播层面，是否能够在第一时间捕获到读者的注意力，进而决定内容是否值得被分享、讨论。

二、底层逻辑
------

**底层逻辑就是研究人群的痛点/兴趣点/需求点。** 

**文章/视频创作不是文学而是心理学。** 

**我们通过分析研究得出读者想看什么内容，我们就写什么内容！**

**也让我感到最扎心的一句话是：没有人关心你，他们只关心自己。**

三、选题公式
------

在以前发表的文章中，《月入3万的爆款选题实操：批量生成10W+阅读量的选题，AI爆文写作原来这样简单！》，我已经给出了详细的选题操作步骤，今天我换个角度来说说选题的实操技巧。

今天给大家一个通用型的公式供大家学习参考。

通用型公式：角色群体+特殊事件+情绪元素+角度立场+价值意义。

**1.角色群体**

即文章的主体，可以是特定人，比如名人、我们自己、家人、朋友，也可以是地域群体，也可以是同类兴趣、同类职业、同类需求的人群；

**2.特殊事件**

事件可以是现实发生的，也可以是即将发生的，或者是虚构的；

**3.情绪元素**

即文章要让读者做出的情绪反应，比如正面情绪（成功、自豪、温暖、正能量等）、负面情绪（孤独、愤怒、愧疚、失败等）或是其他复杂情绪等；

**4.角度立场**

明确表达对事件的看法角度和态度，用事实和逻辑支撑立场；

**5.价值意义**

价值意义可以是信息、知识、情感共鸣等，要确保内容符合读者期待。

举例1：中年职场危机：突破职业瓶颈，重新定义你的工作生涯

```text
角色群体：中年职场人
特殊事件：职业瓶颈期
情绪元素：焦虑、挑战
角度立场：如何突破职业瓶颈，实现自我价值
价值意义：职业发展建议和心理调适方法
```

举例2：年过六十，命里遇到这三个人，是老天在帮你，预示你是有福之人

```text
角色群体：六十岁以上的老年人
特殊事件：遇到三种特定的人（有出息的儿女、懂事的儿媳/女婿、体贴的伴侣）
情绪元素：幸福、满足
角度立场：积极的生活态度和对家庭关系的重视
价值意义：家庭关系在晚年的重要性
```

举例3：许家印的恒大歌舞团：个个貌美如花，身材一流，据传月薪50000，每年开支上亿，网友：大开眼界！

```text
角色群体：恒大歌舞团及其成员
特殊事件：恒大歌舞团的兴衰
情绪元素：惊讶
角度立场：客观叙述，略带讽刺
价值意义：反思与洞察
```

以上，我们完成了通用型的选题。

但是这些选题未必会成为爆款选题，爆款选题需要我们提前设计的。

接下来，我们需要进一步的完善爆款选题的方法论。

想要写出不一样的文章，**我们就要反其道而行之，我们把上面的角色群体、情绪元素、观点立场等进行改变，从中找到一个能引起讨论的点，从而达到我们想要的结果。** 

**1.切换角色群体**

切换角色群体不单单是换个人名或一个类别，而是从事件中找到相关或对立的群体或被忽视的人物，用这样的群体来作为我们新的主体。

比如，一个热点事件大部分文章写的富人这个角度，我们可以从穷人的角度来写文章。

**2.特殊事件**

从小众或偏门的事件找寻切入点。

选择不是热门焦点但具有深刻内涵的事件，或者从一个大事件中挖掘出一个小切入点进行深入探讨。

许家印的恒大歌舞团，就是从许家印的事件中的一个具有讨论度的小众事件切入的，最终成为了一个大话题。

**3.转变角度立场**

要在我们常规而又熟悉的场景、思维和观念里，找到新的角度和认知，这种反常识的冲击力是最强的。

如果大众倾向于一种观点，我们可以尝试站在对立面，或者提出一个全新的观点进行探讨。

比如，一个事件中大家都偏向一个人的立场，我们的立场可以倒向另一个人的立场，给人一种新鲜感或对立感。

**4.情绪元素**

情绪是文章的立脚点，也是最能引导大家讨论的点，我们可以选择与主流不同的情绪表达。

如果大多数内容展现的是正能量、积极向上的情绪，我们可以尝试展现一些真实、深刻的情感，比如挣扎、迷茫等。

**5.价值意义**

从事件中挖掘出非表面或深层次的价值。

而不是提供表面的信息，我们可以尝试引导读者进行深入思考，提供不同的见解和价值。

这点值得注意的是三观要正，符合社会主义的价值观。

四、prompt指令
----------

综上，我们可以得出选题的方法论，进行综合修改为prompt指令如下：

```text
# 角色：写作指导大师

## 简介
版本: 3.6语言: 中⽂描述:擅长创作文章的选题，创作出的选题可以做到篇篇都是爆款文章。

### 技能
不仅懂选题的底层逻辑还懂选题的技巧，根据提示能创作出更高阅读量更多讨论度的选题。

## 规则
创作高阅读量高讨论度的选题，要遵循以下规则。选题公式：角色群体+特殊事件+情绪元素+角度立场+价值意义。
（1）角色群体即文章的主体，可以是特定人，比如名人、自己、家人等，也可以是地域群体，也可以是同类兴趣、同类职业、同类需求的人群。
（2）特殊事件事件可以是现实发生的，也可以是即将发生的，或者是虚构的；
（3）情绪元素文章让群体反应出的情绪，比如正面情绪（自豪、温暖、正能量等）、负面情绪（孤独、愤怒、愧疚、失败等）或是复杂情绪等；
（4）角度立场明确表达角度和要表达的态度，用事实和逻辑支撑立场；
（5）价值意义价值意义可以是信息、知识、情感共鸣等，要确保内容符合读者期待。

## 工作流程
让用户给出要写选题的提示，根据以上的规则您将生成三个部分。
1.写3个选题，每个选题需要用50个字描述；
2.建议（提供3条建议，说明选题中应包含哪些细节以改进）；
3.问题（询问3个最相关的问题，涉及我需要提供哪些附加信息来改进选题）；
如果用户对写出的选题不满意，请针对给出的建议重新修改。
如果用户输⼊"创作新的文章选题"则流程重新开始。

## 初始化
作为 <角色>, 严格遵守 <规则>, 使⽤默认 <中文> 与用户对话，友好的欢迎用户。然后介绍⾃⼰，并告诉用户 <工作流程>。
```

注意prompt指令中【工作流程】的内容，我设计了写选题、建议和问题三个部分，我们可以通过ChatGPT给出的建议和问题，进行修改。
