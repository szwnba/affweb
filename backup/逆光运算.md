MiniMax Code 也有

tui 的那些要么本来就内置，要么手搓也非常方便，比如 omp 和 pi 这些。

Kimi Code cli 也有可以显示的方法，这个我之前写过。

但是 ZCode 之前一直没有提供类似的功能也没提供扩展接口，作为国内使用体验最好的 harness，在我这里使用频率还是很高的。

在它代码开源之后，终于可以比较方便窥探它内部的很多实现。

今天扒了一下它的代码，意外发现它现在也有 TPS Debug 功能了，开启之后可以在侧面板显示 tps 统计信息。

可能有人会问看到这个 tps 有什么用呢？嗯，只能说有哪个老司机不喜欢码表呢？😃![](https://res.wx.qq.com/mmbizappmsg/zh_CN/images/pic/pic_blank.gif)
![](https://res.wx.qq.com/mmbizappmsg/zh_CN/images/pic/pic_blank.gif)

这是今天早上随便测试的一个数据，休息日早上tps 还是可以的。

开启方法

先打开开发者工具

然后找到 console （这个就是和浏览器的开发者工具是一样的）

在 Console 里手动敲：allow pasting

然后再粘贴命令  
localStorage.setItem("zcode:developer-tools:enabled", "1")  
执行成功之后再次打开侧边栏就会发现多了一个功能

点击这个新出现的开发者工具（注意和前面菜单里那个是两个东西），就可以进入 tps debug 页面了。

动态刷新，也不是不能用。
