自动投简历

这是一个自动投简历的开源工具，它可以根据你的简历和工作描述自动使用 ChatGPT 生成一份求职信，并向雇主发送消息。

这是一个完全免费的脚本，你只需要自己配置好 Open AI 的 API 即可使用。希望在寒冷的招聘季节，这个脚本能给你一些帮助，带来一些温暖。

开源地址：https://github.com/Frrrrrrrrank/auto\_job\_\_find\_\_chatgpt\_\_rpa

用电脑控制手机

FreeControl 是一个基于开源项目 scrcpy 使用 C# 语言编写的工具，提供了简洁的交互界面，用于控制和管理 Android 设备

开源地址：https://github.com/pdone/FreeControl

AnimateAnyone

AnimateAnyone 是一个开源项目，主要研究一致性和可控的图像到视频合成技术，用于角色动画。该项目的目标是将静态图像转化为动态视频，实现角色动画的生成。

**抖音上，马斯克跳科目三的视频，背后就是基于这个技术！**

![](https://mmbiz.qpic.cn/sz_mmbiz_png/ePw3ZeGRruwhqHrG0oDNsLuCiafJ45iazaQXmD3XBsenQ9GJSfEoRyV9SFcRVULJ5hhZUQzPk1ZTKbYGibfkYABLw/640?wx_fmt=png&from=appmsg)

这种技术在动画制作、游戏设计、虚拟现实等领域有着广泛的应用前景。项目的详细信息可以在如下页面查看，相关的学术论文也已经在 Arxiv 上发布。

项目地址：https://github.com/HumanAIGC/AnimateAnyone

目前，项目团队正在积极准备公开源代码，还未承诺具体的发布日期，但已经明确表示将会公开源代码。

非官方 Animate Anyone

上一个开源项目 Animate Anyone，截止目前并未公布源代码，而 Open-AnimateAnyone 算是对它的非官方实现。

该项目只在小规模数据集（如 TikTok）上进行训练，由于数据规模和质量不足，很难达到官方的结果。

考虑到时间和成本，项目团队并不打算收集和筛选大量的高质量数据。如果有人有一个在大量高质量数据上训练的稳健模型，并愿意分享，可以提交 pull request。

开源地址：https://github.com/guoqincode/Open-AnimateAnyone
