带走，拿你自己的题材试试
------------

仓库在这里，免费开源：

https://github.com/alchaincyf/huashu-art-motion

把下面这行交给你的agent，让它帮你装：

```
npx skills add alchaincyf/huashu-art-motion
```

环境依赖也让它照着仓库说明装好。然后找一段你真的打算发布的口播，直接说：

```
用huashu-art-motion，把我这段口播做成一段白板解说动画，画面跟着口播里的关键词展开，配字幕，最后给我能直接发布的视频。
```

想做艺术短片，就把你想试的画风、角色和动作告诉它；手上有喜欢的参考视频，也可以一起给它。如果要让自己的形象出镜，需要准备角色图，或者给agent接上生图能力。

最后补一句模型选择。

目前我自己用下来，这个skill在Opus5.5上的效果，远超我试过的其他模型，包括GPT-6 Astra。尤其是画风审美和运动自然度，这两项都差很多。
