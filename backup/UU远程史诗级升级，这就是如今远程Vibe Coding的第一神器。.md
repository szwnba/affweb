在手机上Vibe Coding，用如今一些Coding Agent的终端TUI界面，这体验验终于爽飞了。

可能有些朋友不太熟悉TUI这个词。

简单理解，这玩意就是**长在终端里的图形界面。** 

传统的CLI呢，就是我们上面输入Grok那个文字的时候的界面，几乎就是纯文本的。

然后呢，大家为了在终端里面好用一点，于是造了个TUI，

它们会在终端里面给你画出：

对话框、菜单、按钮、进度条、状态栏、代码块、选项列表等等等等乱七八糟的各种东西，甚至还有可以上下移动和选择的交互界面。

这些东西统称为TUI，也就是Terminal User Interface，终端用户界面。

Claude Code、Grok Build这些Coding Agent，大家平时在终端里看到的那整套交互界面，就是TUI。

虽然看起来还是一堆文字，但你可以选择选项，上下滚动，也会有状态栏、输入框和不同的页面区域。
