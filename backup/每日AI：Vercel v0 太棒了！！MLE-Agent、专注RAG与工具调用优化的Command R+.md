##### **🤖 MLE-Agent：无缝 AI 工程和研究的智能伴侣。** 🔍 与 arxiv 和论文代码集成，提供更好的代码/研究计划🧰 支持 OpenAI、Ollama 等。🎆 Code RAG。

🧰 该工具支持 OpenAI 和 Ollama 等平台，并包含了 Code RAG 功能，用户可以通过该功能执行端到端的 AI 项目、规划 ML 工程任务、调试和修复错误，以及在本地或云端运行代码。

🎆 它还具备交互式聊天模式，可以改进现有的 ML 项目，甚至提供 Kaggle 模式，自动完成 Kaggle 任务。

![](https://mmbiz.qpic.cn/mmbiz_png/Sn1tJhGWmibsib2MXYWoF62P9kCQaENygOk62xckzfVXMCro7XBicZuNt2eko2x4AtaIJicFmHS3lSsnTAMMHcS0EQ/640?wx_fmt=png&from=appmsg)

C4AI Command R+ 08-2024 1040 亿参数模型，具有非常先进的功能，包括检索增强生成 (RAG) 和用于自动执行复杂任务的工具。

Command R+ 08-2024 的工具使用功能将对话作为输入（带有可选的用户系统前言），以及**可用工具列表**。然后，该模型将生成一个 JSON 格式的操作列表，以在这些工具的子集上执行。

![](https://mmbiz.qpic.cn/mmbiz_png/Sn1tJhGWmibsib2MXYWoF62P9kCQaENygOOqoR8BPvDicvx7M6TXCkVIiciab8ynsnO8VovWSRrQXCicXEu2fuz54NCQ/640?wx_fmt=png&from=appmsg)

该模型已接受过识别特殊directly\_answer工具的训练，它使用该方法来避免过多的工具调用。在多种情况下，例如问候用户或询问澄清问题时，避免调用特定工具的功能非常有用。

![](https://mmbiz.qpic.cn/mmbiz_png/Sn1tJhGWmibsib2MXYWoF62P9kCQaENygOUe1YWdMSOY0DNVbZzEwtYAAOIDFeiccvFnIhmKLemXmJQHiasKJSIOPg/640?wx_fmt=png&from=appmsg)

另一方面，小型配套型号是C4AI Command R 08-2024 则适合更简单的检索增强生成(RAG) 和单步工具使用任务，以及它提供更低的价格。

![](https://mmbiz.qpic.cn/mmbiz_png/Sn1tJhGWmibsib2MXYWoF62P9kCQaENygO29MnibYEn4vwVLxG4QOuJGoicXZelOTvB5obneltOiamBkTmX3mGd8c2A/640?wx_fmt=png&from=appmsg)
