### 1 启动应用

首先，按照文章开头提示下载好本项目完整源码解压后，在**「项目根目录」**打开终端，激活你的`Python`虚拟环境（推荐使用`3.10`版本），接着执行`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`，完成当前项目依赖库的安装。

然后直接在终端执行`python app.py`即可启动应用，按照控制台提示的信息，浏览器访问本地`http://127.0.0.1:8050`地址即可访问应用：

### 3 应用开发重点思路

作为一个轻量的`Dash`应用，其项目结构非常简单：

*   `app.py`中构建了应用的页面内容及交互计算逻辑，其中导出海报图片的功能，底层原理是基于`fuc`中的`FefferyDom2Image`组件，它可以快捷的将指定**「页面元素」**转换为**「图片数据」**
    
*   `utils.py`中封装了应用中可复用的一些逻辑到自定义函数中
    
*   `assets`目录是应用默认的静态文件目录，用于存放应用的logo图片等文件
    
*   `测试数据表.xlsx`则存储了海报渲染依赖的相关数据表
    

因为是基于`Python`中的`Dash`框架进行开发，因此该应用的实现过程全部使用`Python`编写，无需学习复杂的`javascript`等语言，在此应用基础上进行二次开发非常的灵活高效。
