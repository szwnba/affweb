01

什么是 ProPush Constructor？

Constructor 是 ProPush 推出的一款流量变现工具，核心是一套经过预先测试的落地页模板。模板以压缩包形式提供，下载后即可部署和使用。

压缩包中包含模板所需的全部文件。你可以根据自己的需求修改设计、调整页面结构，并进一步优化内容，让页面更适合自己的流量来源和变现策略。

模板生成并下载后，可以直接部署到自己的服务器。每套模板都已经包含经过测试的用户流程，你可以根据实际需求选择更注重用户互动的较长流程，也可以采用更简洁、更侧重转化的页面形式。

Constructor 的一大特点，是在页面中加入了多层变现机制。每个页面最多可以设置 9 个变现区域，通过不同的用户行为触发跳转，同时结合经典 Push 通知，在多个互动环节创造收益。

这些变现方式会通过智能广告轮换机制相互配合，尽可能提高每一次用户互动所带来的价值。

如果你希望先从简单的方式开始，也可以直接使用默认模板。默认版本已经具备完整功能，可以直接上线，也更适合第一次使用 Constructor 的用户。

02

为什么值得尝试 Constructor？

很多广告主和品牌都会提供现成素材或页面模板，但这些内容通常并不是按照发布商自身的收益目标来设计的。

实际使用中，往往会遇到一些限制，比如页面修改空间较小、用户流程难以调整、测试方式有限，也很难在同一个页面中加入多种变现方式。

换句话说，你负责带来流量，却不一定能够充分掌控这些流量最终如何产生收益。

Constructor 希望改变这一点。它让联盟营销从业者和发布商能够更自由地管理页面、调整转化流程，并根据实际表现不断测试和优化。

更自由地控制页面和流程

使用 Constructor 后，你不再需要完全依赖别人提供的固定页面。

模板可以部署在自己的服务器上，页面中的文字、视觉元素和结构都可以根据需要进行调整。你还可以测试不同的转化流程和页面方案，并将效果更好的版本进一步扩大。

也就是说，你不仅可以掌握流量来源，还能更直接地控制用户进入页面后的整个流程。

多层变现，让同一批流量创造更多价值

一套模板，并不意味着只能有一种收益来源。Constructor 可以在同一个转化流程中加入多个变现节点，让不同的用户行为都有机会产生收益。

1 · 点击变现

当用户点击页面内容时，可以触发 Popunder，并在新的标签页中打开。

2 · Push 互动

当用户与 Push 通知进行互动时，也可以带来额外收益。

3 · 退出与其他变现场景

当用户离开页面，或者没有满足特定条件时，也可以通过其他方式继续对这部分流量进行变现。

因此，一套模板中可以包含多个变现节点，帮助你从同一批流量中获得更多收益。

Constructor 的设置方式也比较灵活。大部分变现逻辑可以直接通过界面管理；如果需要更深入的自定义，也可以从代码层面进行修改。

模板中包含保证整个流程正常运行所需的基础设置，同时也提供 Push 通知等可选变现功能。

从技术上来说，你可以根据需要关闭部分功能。不过，对于刚开始使用 Constructor 的用户，我们更建议先保留完整的默认配置，因为这套结构已经经过测试。删除过多组件，可能会影响整体收益表现。

即使部分用户没有完成主要转化动作，其他变现方式仍然有机会继续发挥作用，让同一批流量产生更多价值。

更清晰的数据追踪

除了多层变现，Constructor 还提供了较完整的数据追踪功能，帮助你了解每个环节的实际表现。

Zone Tracking

每个变现区域都可以单独追踪。

Detailed Stats

查看哪些环节带来的收益更多。

API Access

通过 API 将表现数据接入自己的分析系统。

Postback Support

将相关数据发送到第三方 Tracker，并使用现有的分析方式评估 Campaign 表现。

由于每个变现区域都可以独立追踪，你可以更清楚地看到哪些部分表现最好、哪些环节还有优化空间，以及主要收益来自哪里。

在 ProPush 平台中，可以直接查看详细的 Zone 级别统计数据。如果需要进行更深入的分析，也可以通过 API 获取数据，并接入自己的报表或分析系统。

对于已经使用外部 Tracker 的团队，Constructor 同样支持灵活的 Postback 设置，可以将所需数据传递到现有的追踪系统中，无需改变原有的数据分析流程。

更快测试，更快扩大效果

有了 Constructor，你不需要只测试一个版本。

**每天都可以创建不限数量的转化流程**，用来测试不同的页面方案、适配不同 GEO，并根据实际流量表现及时调整。

对于需要持续测试页面、结构和变现方式的团队来说，这能够提高测试效率，也能更快找到适合不同流量的方案。

针对不同流量提前优化

Constructor 的模板并不是从零开始制作的。

在设计这些模板时，ProPush 已经考虑了不同流量的特点，并根据以往表现较好的页面结构进行了测试和优化。

因此，你拿到的并不是一张完全空白的页面，而是一套已经具备基础结构和用户流程的模板。在这个基础上，你仍然可以根据自己的推广项目、流量来源和用户行为继续调整页面，让模板更符合实际需求。

如何获得自己的 Constructor？

开始使用 Constructor 的流程并不复杂。

1登录并进入 Constructor

登录你的 ProPush 账户，进入 Constructor 页面。

2提交申请

提交申请，并说明你的流量情况和目标。提供的信息越完整，团队就越容易了解你的需求，也有助于更快完成审核。

3完成流量质量检查

作为审核流程的一部分，你可能还需要完成流量质量检查。

4选择模板

选择一套基于成熟转化流程设计的现成 HTML 模板。

5下载、部署并上线

下载模板压缩包，并将其部署到自己的服务器。

默认版本已经具备完整功能，因此无需一开始就进行大量修改。你可以先直接发送流量，观察实际表现，再根据数据逐步进行优化。

当你准备进一步调整时，可以修改模板中的文字、视觉元素和页面结构。所需文件都会包含在压缩包中，同时还会提供相关技术文档，帮助你完成设置。

Constructor 提供了较高的自定义空间，但对于第一次使用的用户，我们更建议先从经过测试的默认版本开始。先观察流量和基础表现，再逐步调整页面，通常会更加稳妥。过早进行大幅修改，反而可能影响原本已经经过测试的效果。
