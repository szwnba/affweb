前段时间 Codex的 Remote Control 功能挺火的。

在电脑上跑一个编程任务，然后掏出手机，扫个码，就能从沙发上继续盯着这个任务跑。听起来很未来对吧。

我第一时间体验了，也确实好用。但用了两周之后我发现一个问题，Remote Control 只能控制 Codex的会话。什么意思呢，就是你手机上看到的是 Codex 界面，你能看它写代码、看它跑测试、给它发指令。

![](https://mmbiz.qpic.cn/mmbiz_png/UzsCVuwOnvS8HVsYkH7GKTYbM82qicqPnkLmDpu96ShkjowqaYq2ITY6Rmm8gxOYYcRBQnoyUk8dmTNSyt5wNV5WAgv5v5wKZTIY50cSibONo/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=0)

但如果你想在电脑上干点别的呢？

比如 Codex 正在跑一个接口测试，你突然想看一眼浏览器里的某个页面，或者想操作一下 Postman 发个请求，或者想在 Finder 里找个文件。这些操作，Codex 中的Remote Control 帮不了你。

它管的是「你的 AI 编程会话」，不是「你的电脑」。

这时候你就需要一个真正的远程控制工具了。

02AI 时代的远程办公
------------

回到正题。

Codex 的 Remote Control 解决的是「AI 编程会话的移动接管」。你在电脑上让 Codex 跑一个任务，然后出门了，路上掏出手机看看进度、发个指令。

但真实的远程办公场景，远不止盯一个编程会话。

**场景一，AI 在干活，你去干别的了。** 

Codex 在电脑上跑一个完整的测试回归，预计要 20 分钟。你下楼吃饭去了，吃到一半想看看进度。用 Remote Control 只能看 Codex 的终端，用 UU 远程可以看整台电脑——包括你之前开着的浏览器调试页面、数据库客户端、Docker 面板。

**场景二，AI 卡住了，需要你手动救场。** 

Codex 有时候会遇到环境问题，比如端口被占用、浏览器驱动没装好。这些问题 Remote Control 里你只能看终端干着急，因为你要操作的是系统设置、终端命令、甚至文件管理器。UU 远程直接给你完整的桌面操作权限，该怎么修就怎么修。

**场景三，不用 AI 的时候。** 

远程办公不可能全是编程。回个邮件、看个文档、调一下 Figma 的设计稿、给同事演示一下页面。这些事情 Codex 帮不了你，但 UU 远程都能干。

所以我的用法是**两个搭着用**。

电脑上 Codex 跑任务，手机装两个 App。日常盯进度用 Codex 的 Remote Control（轻量、快），需要操作整台电脑时切到 UU 远程（完整桌面、全功能）。两者不冲突，各管各的。

用一句话总结区别。

**UU 远程是「你的手伸到了远处的电脑上」，Codex RC 是「你的眼睛盯住了 AI 的会话」，WorkBuddy 是「你雇了一个坐在你电脑前的 AI 助手」。** 

三者不是替代关系，是三个不同层次的东西。

*   • 你想**远程操控**电脑 → UU 远程
    
*   • 你想**远程监督** AI 编程 → Codex RC
    
*   • 你想让 **AI 替你操作**电脑 → WorkBuddy
    

但说实话，现阶段 WorkBuddy 这类桌面 Agent 的能力还比较早期。让 AI 自主操作你的电脑，听上去很酷，实际用起来经常翻车——点错按钮、打开错误的文件、在终端里删错东西。AI 的操作精度和判断力还没到能放心放手的地步。

所以目前我的推荐还是，**需要远程操作就用 UU 远程自己动手，需要盯 AI 就用 Codex RC，想尝鲜 AI 全自动就试试 WorkBuddy，但别把重要工作全交给它。** 

04UU 远程在 AI 工作流里的几个实战用法
-----------------------

分享几个我实际在用的场景。

**用法一，出门后远程检查 AI 任务。** 

电脑上同时跑着 Codex 写代码、另一个终端跑 pytest 回归测试、本地服务在 8000 端口挂着。人在外面，掏出手机打开 UU 远程，整台电脑桌面都在眼前。切到终端看测试跑完没，切到浏览器确认页面渲染正常，切到 Codex 看看它代码写完没。一个 App 全搞定。

**用法二，人在外面，突然要给朋友发一份电脑里的文件。** 

上班出门忘了带一份重要文档，同事在微信上催你要。文件在电脑桌面上，人已经在外面了。用 UU 远程连回电脑，打开桌面找到那个文件，直接用 UU 的文件传输功能拖过来，不限大小不限格式，几秒钟到手机上，转发给同事。整个过程不需要跑回去开电脑，也不需要求人帮你远程操作。

05安全这块放不放心
----------

用远程控制软件，最担心的就是安全性。毕竟等于把你电脑的完整控制权暴露在网络上了。

UU 远程在这块的做法。

*   • 网易出品，通过了 ISO 27001（信息安全管理）和 ISO 27701（隐私信息管理）两项认证
    
*   • 有防窥模式，被控时可以一键遮挡屏幕，防止旁边的人偷看
    
*   • 每次连接需要 ID 加验证码双重确认
    
*   • 可以设置被控结束后自动锁屏
    

对于日常办公场景，这个安全等级够用了。当然，如果你管的是生产服务器或者涉密数据，建议还是别开远程，老老实实去机房。
